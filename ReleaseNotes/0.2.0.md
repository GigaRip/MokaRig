### New
- Clipboard sharing for macOS guests. Copy text and images between your Mac and a macOS virtual machine running macOS 15 or later. It's on by default for new virtual machines, and you can turn on Share Clipboard in Configure for existing ones.
- MokaRig Guest Tools. A disk in the guest with the MokaRig Guest Agent installer, which clipboard sharing needs. Open the disk in the guest and run the installer once, then turn off Attach Guest Tools in Configure.
